# Sanskrit Studio V7 — Typing Only

A focused browser-only Sanskrit typing workspace designed for GitHub Pages.

## Included

- Direct Devanāgarī typing
- Full on-screen Sanskrit keyboard with all core letters visible at once
- Vowels, consonants, mātrās, signs, punctuation, numbers, and common conjuncts
- Devanāgarī → IAST live view
- Optional IAST → Devanāgarī conversion
- Dark/light mode
- Undo/redo
- Find/replace
- Autosave in browser localStorage
- Copy
- Character and word counts
- Adjustable font size
- TXT export
- Word-compatible DOC export
- PDF via browser print
- SRT export
- VTT export
- CSV export
- Responsive layout
- No microphone
- No speech recognition
- No audio upload
- No backend
- No API keys
- No paid services

## GitHub Pages

Set GitHub Pages to deploy from `main` and `/docs`.

Everything runs directly in the browser.
