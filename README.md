# Sanskrit Studio V8

Typing-only Sanskrit workspace for GitHub Pages.

Included: direct Devanāgarī typing, full on-screen keyboard, IAST view, IAST→Devanāgarī conversion, dark/light mode, autosave, undo/redo, find/replace, copy, font sizing, counts, TXT/Word/PDF/CSV export.

No speech, audio upload, backend, API keys, or paid services.

Deploy with GitHub Pages from `main` → `/docs`.
