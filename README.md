# Sanskrit Studio V9

All site files live in the same folder. Add your official `FSL_logo.png` beside `index.html`.

## Included
Write + Dictionary, multiple renameable document tabs, IndexedDB autosave, save indicator, rich-text formatting, floating keyboard, Roman/IAST→Devanāgarī, live IAST view, right-click dictionary lookup, dictionary→editor insertion, Trash/Recently Deleted, history snapshots, workspace backup/import, Settings modal, searchable Help drawer, keyboard shortcuts, and FSL branding.

## GitHub Pages
Publish the folder containing `index.html`. If these files are at repository root:
Settings → Pages → Deploy from a branch → main → / (root)

## Dictionary
V9 loads `dictionary.json` beside `index.html`. Replace the starter file with a larger dictionary using the same format. See `DICTIONARY_SETUP.md`.
