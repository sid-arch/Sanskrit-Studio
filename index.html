How to Use

Everything in V9

Documents

Press ＋ to create documents. Double-click a tab name to rename it. Closing a tab sends it to Trash.

Saving

V9 stores documents in IndexedDB. They survive reloads, hard reloads, closing Chrome, and restarting the same device. Cross-device sync is not automatic.

Formatting

Select text, then use Bold, Italic, Underline, Highlight, alignment, and list controls. Ctrl/Cmd+B, I and U also work.

Roman → Devanāgarī

Choose Roman → Devanāgarī. Examples: ahaṃ paśyāmi → अहं पश्यामि, kṛṣṇaḥ → कृष्णः. Easy aliases include aa, ii, uu, .r, .n, .s, .m and .h.

Floating Keyboard

Drag the keyboard by its title bar. Minimize or close it, then reopen with ⌨ Keyboard. Recent characters stay at the top.

Dictionary

Search in Devanāgarī or IAST. Select a word in Write and press Lookup, or right-click the selection. Dictionary results can be inserted directly into the active document.

Trash & History

Trash lets you restore deleted documents. History stores automatic snapshots and lets you restore older content.

Workspace Backup

Settings → Export Workspace creates one JSON backup containing documents, trash, history and settings. Import Workspace restores it.

Keyboard Shortcuts

Ctrl/Cmd+B bold • I italic • U underline • Z undo • Shift+Z redo • S save • N new document • K toggle Sanskrit keyboard • Shift+D selected-word dictionary lookup.

Branding

Put FSL_logo.png in the same folder as index.html. It appears in the header and footer automatically.
