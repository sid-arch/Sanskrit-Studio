How to Use Sanskrit Studio

Everything in V11, explained.

Getting Started

Write is your document workspace. Dictionary lets you search Sanskrit words. Your documents are automatically stored on this browser using IndexedDB.

Documents & Tabs

Use ＋ to create a document. Double-click a document tab name to rename it. Closing a tab moves that document to Trash instead of deleting it permanently.

Saving & Persistence

The top-right indicator shows Saving… and then Saved locally. Documents survive reloads, hard reloads, browser restarts, and device restarts on the same browser/device. Clearing browser site data can erase them, so use Workspace Backup for important work.

Formatting

Select text and use Bold, Italic, Underline, Highlight, alignment, or list controls. Shortcuts: Ctrl/Cmd+B, Ctrl/Cmd+I, Ctrl/Cmd+U, Ctrl/Cmd+Z, and Ctrl/Cmd+Shift+Z.

Roman → Devanāgarī

Switch the input mode to Roman → Devanāgarī. Example: ahaṃ paśyāmi → अहं पश्यामि. Easy aliases include aa → ā, ii → ī, uu → ū, .r → ṛ, .n → ṇ, .s → ṣ, .m → ṃ, and .h → ḥ.

Floating Keyboard

The Sanskrit keyboard is docked to the bottom of the screen. It never moves or drifts. Minimize it with the minus icon or close it with ×. Reopen it from the header or with Ctrl/Cmd+K. The editor automatically leaves room for the docked keyboard.

Dictionary

Search in Devanāgarī or IAST. Inside Write, select a Sanskrit word and choose Lookup, or right-click the selection and choose Look up selected word. Dictionary results can be inserted directly back into the current document.

History

V10 automatically creates document snapshots. The History button first saves your current document, creates a fresh snapshot, and then shows earlier versions. Restoring a snapshot first protects your current version with another snapshot.

Trash / Recently Deleted

Closed documents are moved to Trash. You can restore them or permanently delete them. Sanskrit Studio always keeps at least one active document in Write.

Moving Work Between Devices

Automatic cross-device sync is not included. Open Settings → Export Workspace to download a JSON backup containing documents, Trash, History, and settings. Import that file on another device.

Keyboard Shortcuts

Ctrl/Cmd+B Bold • I Italic • U Underline • Z Undo • Shift+Z Redo • S Save now • N New document • K Toggle keyboard • Ctrl/Cmd+Shift+D Dictionary lookup.

FSL Logo

Place your official FSL_logo.png beside index.html. V10 uses it in the header and footer with rounded corners. If it is missing, a simple fallback mark appears.
